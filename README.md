# Project Files for Web Application

This project consists of a series of files intended to be published as a static GitHub Pages website. The site features a responsive design built with Tailwind CSS and provides access to diverse content including a short story, JSON data, an SVG image, and textual descriptions.

## Files Included

- `ashravan.txt`: A creative short story about Ashravan after Shai's restoration.
- `dilemma.json`: JSON data presenting a moral dilemma involving an autonomous vehicle.
- `about.md`: A brief description of oneself in three words.
- `pelican.svg`: An SVG graphic of a pelican riding a bicycle.
- `restaurant.json`: A recommendation for a good restaurant in Chennai.
- `prediction.json`: An estimation of the Fed Funds rate in December 2025.
- `index.html`: The homepage linking to all of the above files.
- `LICENSE`: MIT License text.
- `uid.txt`: Contains an uploaded UID attachment.

## Deployment

Host these files on GitHub Pages by committing to the `main` or `gh-pages` branch of your repository. Ensure that the URLs are accessible directly.

## Usage

Navigate to the site URL in a web browser to explore the collection of files via the homepage, which provides links and descriptions.
